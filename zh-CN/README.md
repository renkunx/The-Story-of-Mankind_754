# 人类的故事（中文译本）

本目录是房龙《人类的故事》（*The Story of Mankind*, 1922）的简体中文译本，用于「卷里阅读」小程序。

- 作者：Hendrik Willem van Loon（亨德里克·威廉·房龙）
- 英文原文：Project Gutenberg eBook #754，Public Domain in the USA
- 底本仓库：[GITenberg/The-Story-of-Mankind_754](https://github.com/GITenberg/The-Story-of-Mankind_754)
- 英文分章原文见本仓库 `en/` 目录，便于对照。

译文按原书顺序收录：前言、第 1–63 章、附录 A《关于本书插图》、附录 B《儿童历史阅读书单》。人名、地名采用通行中文译名，年代与史实以原文为准。
