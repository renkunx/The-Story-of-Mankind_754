# 第 50 章 · 重商主义

*欧洲新近建立的民族国家或王朝国家如何设法使自己致富，以及重商主义的含义*

我们已经看到，在十六和十七世纪，我们现代世界的各个国家如何开始成形。它们的起源几乎各不相同。有些是某个国王刻意努力的结果。有些是偶然发生的。还有些是有利的自然地理边界造成的结果。但一旦建立，它们全都试图加强内部行政，并对外事务施加尽可能大的影响。这一切当然花费巨大。中世纪国家缺乏中央集权，并不依赖充盈的国库。国王从王室领地取得收入，他的行政机构自己养活自己。现代中央集权国家则是更复杂的东西。旧日的骑士消失了，取而代之的是受雇的政府官员或官僚。陆军、海军和内部行政都需要数以百万计的钱。于是问题变成了：这笔钱从哪里来？

在中世纪，金银是稀有商品。正如我告诉过你的，普通人一辈子也没见过一枚金币。只有大城市的居民才熟悉银币。美洲的发现和秘鲁银矿的开发改变了这一切。贸易中心从地中海转移到大西洋沿岸。意大利古老的“商业城市”失去了金融上的重要性。新的“商业国家”取而代之，金银不再是稀罕物。

贵金属经由西班牙、葡萄牙、荷兰和英国流入欧洲。十六世纪有它自己的政治经济学作家，他们发展出一套国民财富理论，在他们看来，这理论完全可靠，对其各自国家有莫大的好处。他们推论说，黄金和白银都是真正的财富。因此他们相信，国库和银行金库里现金储备最多的国家，同时就是最富的国家。而既然金钱意味着军队，那么最富的国家也就最强大，可以统治世界其余部分。

我们称这套体系为“重商主义”（Mercantile System），它被接受时的那种不容置疑的信仰，就像早期基督徒相信奇迹、如今许多美国商人相信关税一样。在实践中，重商主义的运作如下：要获得最大的贵金属盈余，一个国家必须有有利的出口贸易差额。如果你向邻国出口的货物多于邻国向你出口的，他就欠你钱，不得不把一些黄金送给你。于是你赚他亏。由于这一信条，几乎每个十七世纪国家的经济纲领都是这样：

1. 设法占有尽可能多的贵金属。

2. 鼓励对外贸易优先于国内贸易。

3. 鼓励那些把原料变成可出口制成品的产业。

4. 鼓励众多人口，因为你需要工厂工人，而农业社会产生不了足够的工人。

5. 让国家监督这一过程，必要时加以干预。

十六和十七世纪的人不把国际贸易看作某种类似自然力的东西——它总会服从某些自然规律，不管人如何干预——而是试图借助官方敕令、王家法律和政府财政援助来管制商业。

十六世纪，查理五世（Charles V）采纳了这套重商主义（当时还是全新的东西），并把它推行到他的众多领地。英国的伊丽莎白仿效他，算是给他捧场。波旁家族（Bourbons），尤其是国王路易十四（Louis XIV），是这一学说的狂热信徒；他伟大的财政大臣柯尔贝尔（Colbert）成了重商主义的先知，全欧洲都向他寻求指导。

克伦威尔（Cromwell）的整个外交政策都是重商主义的实际应用。它无一例外地针对富裕的对手荷兰共和国。因为荷兰船主作为欧洲商品的承运人，有某种自由贸易倾向，因此必须不惜一切代价加以摧毁。

不难理解这样的体系会如何影响殖民地。在重商主义下，殖民地仅仅成为金银和香料的蓄水池，供宗主国汲取。亚洲、美洲和非洲的贵金属供应以及这些热带国家的原料，成了恰好拥有那块殖民地的国家的垄断物。外人绝不许进入其境，本地人也不得与挂外国旗的商人贸易。

毫无疑问，重商主义促进了某些国家新兴工业的发展，那些国家以前从未有过制造业。它修路开渠，改善了运输手段。它要求工人有更高的技能，提高了商人的社会地位，同时削弱了地主贵族的势力。

另一方面，它造成了极大的苦难。它使殖民地原住民成为最无耻剥削的牺牲品。它使宗主国的公民面临更可怕的命运。它在很大程度上把每个国家变成武装营地，把世界分割成一小块一小块的领土，每一块都只为自己的直接利益运作，同时时刻设法摧毁邻国的力量、夺取它们的财宝。它如此强调拥有财富的重要性，以致“有钱”被视为普通公民唯一的美德。经济体系像外科手术和妇女服装的时尚一样来去更替；十九世纪时，重商主义被抛弃，代之以自由公开竞争的制度。至少，人们是这样告诉我的。
